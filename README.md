## About

I'm a full-stack developer working end to end — database schema and API design through to the
interface people actually use. Most of my work is **production systems for real organizations**:
institute management platforms, attendance and memorization tracking, ERP portals, and media sites,
built Arabic-first with full RTL support.

- 🔭 Currently building management platforms for educational and charitable institutions
- 🧩 Comfortable across **PHP/Laravel**, **Node/Express**, **Java/Spring Boot**, **React + TypeScript**
- 🤖 I use AI where it earns its place — transcription pipelines, translation, content tooling
- 🌍 Arabic &amp; English · RTL-first UI is a default for me, not an afterthought
